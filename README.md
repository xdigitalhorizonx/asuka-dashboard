# Asuka Langley Command Center

Dark-mode ops dashboard for conversations with the Asuka Langley Grokbot agent.

- Reminders (add / complete / remove)
- Calendar of due dates
- Notes
- Attachments
- CRM kanban: New Lead, Proposal Sent, Closed/Won, Lost
- JSON export / import (stored in the browser)

```bash
npm install
npm run dev
```
